# UI Design System

## 1. 设计原则

本项目视觉定位是“内容产品 + 效率工具”，界面要帮助用户快速发现、比较、学习和使用 AI 工具。

核心原则：

| 原则 | 说明 | 落地要求 |
|---|---|---|
| 信息优先 | 用户来这里是找工具、看教程、复制提示词、做对比 | 避免大面积装饰图、霓虹科技风和营销式 hero |
| 可扫描 | 页面应适合快速浏览和比较 | 卡片字段稳定，表格对齐，标签含义一致 |
| 轻科技 | 视觉要现代可信，但不过度炫技 | 使用浅背景、清晰边框、少量蓝紫强调色 |
| 内容可信 | 推荐、广告、赞助必须区分 | 商业位使用明确 Badge 标注 |
| SEO 友好 | 页面结构服务内容层级 | H1、分区标题、卡片标题和表格结构清晰 |
| 移动稳定 | 移动端不能横向溢出 | 卡片、筛选器、表格必须有响应式规则 |

不建议的方向：

- 老式网址导航黄页
- 黑客终端风
- 满屏霓虹科技风
- 广告堆叠门户站
- 首页资讯流
- 大而空的营销落地页

### 语义颜色使用

- 主 CTA：蓝色。
- 教程/提示词入口：紫色或紫色浅底。
- 免费标签：绿色。
- 赞助/广告标签：黄色。
- 风险、不适合、限制：红色。

## 3. 字体层级

默认字体使用系统无衬线字体，中文优先保证可读性。

| 层级 | 尺寸 | 行高 | 字重 | 用途 |
|---|---:|---:|---:|---|
| Display | 40px | 48px | 700 | 首页 H1，仅首屏使用 |
| H1 | 32px | 40px | 700 | 页面主标题 |
| H2 | 24px | 32px | 700 | 页面一级分区 |
| H3 | 20px | 28px | 600 | 卡片区块标题 |
| H4 | 18px | 26px | 600 | 小区块标题 |
| Body | 16px | 26px | 400 | 正文 |
| Body Small | 14px | 22px | 400 | 卡片描述、表格内容 |
| Caption | 12px | 18px | 500 | Badge、元信息、辅助说明 |

规则：

- 卡片内不要使用 hero 级大字。
- 工具名、教程名、对比标题最多两行截断。
- 正文段落行宽建议控制在 680-760px。
- 中文正文不使用负 letter-spacing。

## 4. 间距规范

基础间距采用 4px 网格。

| Token | 值 | 用途 |
|---|---:|---|
| `space-1` | 4px | 图标与文字间距 |
| `space-2` | 8px | Badge 组、紧凑元素 |
| `space-3` | 12px | 卡片内部小间距 |
| `space-4` | 16px | 默认卡片 padding |
| `space-5` | 20px | 表单组、列表组 |
| `space-6` | 24px | 区块内部间距 |
| `space-8` | 32px | 页面分区间距 |
| `space-10` | 40px | 大分区间距 |
| `space-12` | 48px | 首页主要分区 |

页面宽度：

- 内容最大宽度：`1200px`
- 文章正文最大宽度：`760px`
- 对比表格最大宽度：`100%`
- 页面左右 padding：移动端 16px，平板 24px，桌面 32px

## 5. 圆角规范

整体圆角克制，不做过度圆润的玩具感 UI。

| Token | 值 | 用途 |
|---|---:|---|
| `radius-sm` | 4px | Badge、表格内标签 |
| `radius-md` | 6px | 输入框、按钮 |
| `radius-lg` | 8px | 卡片、筛选器、表格容器 |
| `radius-xl` | 12px | 首页搜索容器、重点模块 |

规则：

- 默认卡片使用 8px。
- 按钮使用 6px。
- Badge 使用 4px。
- 不使用大面积胶囊形容器承载长文本。

## 6. 阴影规范

阴影只用于轻微层级，不制造漂浮感。

| Token | 值 | 用途 |
|---|---|---|
| `shadow-xs` | `0 1px 2px rgba(15, 23, 42, 0.04)` | 输入框、轻卡片 |
| `shadow-sm` | `0 1px 3px rgba(15, 23, 42, 0.08)` | 默认卡片 hover |
| `shadow-md` | `0 8px 20px rgba(15, 23, 42, 0.08)` | 下拉、弹层 |

规则：

- 默认卡片主要靠边框区分，少用阴影。
- hover 可轻微提升阴影，但不能造成布局位移。
- 移动端减少阴影，优先用边框。

## 7. 按钮规范

### 类型

| 类型 | 用途 | 视觉 |
|---|---|---|
| Primary | 主操作，如搜索、提交、查看详情 | 蓝底白字 |
| Secondary | 次级操作，如查看教程、查看对比 | 白底深色字，浅边框 |
| Ghost | 导航、轻操作 | 透明底，hover 浅灰 |
| Success | 复制提示词、免费工具入口 | 绿或蓝色强调 |
| Warning | 赞助合作入口 | 黄色浅底或黄边框 |

### 尺寸

| 尺寸 | 高度 | Padding | 用途 |
|---|---:|---|---|
| Small | 32px | 12px | 卡片内操作 |
| Medium | 40px | 16px | 默认按钮 |
| Large | 48px | 20px | 首页搜索 CTA |

规则：

- 按钮文案使用动作词：`查看详情`、`复制提示词`、`查看对比`、`提交工具`。
- 工具类图标按钮必须有 tooltip 或 aria-label。
- 同一卡片内主按钮最多一个。

## 8. Badge/标签规范

Badge 用于快速表达工具属性，不能堆到影响阅读。

| Badge | 样式 | 用途 |
|---|---|---|
| 免费 | 绿字绿浅底 | 免费工具或有免费额度 |
| 付费 | 灰字灰浅底 | 付费工具 |
| 国内可用 | 蓝字蓝浅底 | 中文用户可访问 |
| 需魔法 | 黄字黄浅底 | 访问有限制 |
| 推荐 | 蓝底白字 | 编辑推荐 |
| 赞助 | 黄底深色字 | 商业位 |
| 教程 | 紫字紫浅底 | 有教程 |
| 提示词 | 紫字紫浅底 | 有 prompt |
| 新收录 | 蓝字蓝浅底 | 新增工具 |

规则：

- 卡片内最多展示 4 个 Badge。
- 商业 Badge 必须固定可见，不得隐藏在 hover 中。
- 同一语义全站统一颜色。

## 9. 搜索框规范

搜索是首页和工具发现的核心控件。

### 首页搜索

- 高度：56px。
- 圆角：12px。
- 左侧搜索图标。
- placeholder 示例：`搜索工具、任务或场景，例如：AI 做 PPT、Kimi、周报提示词`。
- 右侧主按钮：`搜索`。
- 下方可展示热门搜索词。

### 列表页搜索

- 高度：40px 或 44px。
- 支持工具名、标签、场景关键词。
- 与筛选器同一行，移动端垂直堆叠。

### 搜索结果

结果类型要清晰区分：

- 工具
- 教程
- 提示词
- 对比
- 分类

每条结果显示标题、类型 Badge、简短说明。

## 10. 工具卡片规范

工具卡片是全站最高频组件，必须紧凑、可比较。

### 卡片字段

| 字段 | 必填 | 说明 |
|---|---:|---|
| Logo/首字母图标 | 是 | 无 Logo 时使用首字母 |
| 工具名 | 是 | 最多两行 |
| 一句话用途 | 是 | 说明解决什么任务 |
| 分类 | 是 | 如写作、办公、编程 |
| 价格 Badge | 是 | 免费/付费/有免费额度 |
| 可访问性 | 建议 | 国内可用/需魔法 |
| 推荐理由 | 推荐卡必填 | 不写空泛形容词 |
| 操作 | 是 | 详情、教程、对比 |

### 卡片尺寸

- 桌面三列或四列网格。
- 分类页建议三列。
- 首页推荐区最多 8 张。
- 移动端单列。

### 状态

- 默认：白底、浅边框。
- Hover：边框变蓝或轻阴影。
- 赞助：显示赞助 Badge，不改变成广告大横幅。

## 11. 教程卡片规范

教程卡片强调“能完成什么任务”。

字段：

- 教程标题
- 场景 Badge
- 涉及工具
- 预计耗时
- 适合人群
- 是否附提示词
- 简短摘要

视觉规则：

- 标题最多两行。
- 摘要最多两行。
- `附提示词` 使用紫色 Badge。
- 教程列表页可用双列，移动端单列。

## 12. 对比表格规范

对比表用于降低决策成本。

结构：

| 区域 | 说明 |
|---|---|
| 顶部结论 | 先给选择建议 |
| 摘要表 | 价格、中文支持、适合场景、上手难度 |
| 详细表 | 功能、限制、输出质量、适合人群 |
| 场景建议 | 按用户任务给建议 |

视觉规则：

- 首列固定为对比维度。
- 重要结论用浅蓝或浅绿背景突出。
- 移动端表格允许横向滚动，但外层必须有边界和提示。
- 不用过多颜色，避免像报价页。

## 13. 首页布局规范

首页目标：第一屏让用户知道这是“AI 工具选择 + 教程 + 提示词 + 对比”的产品。

推荐顺序：

1. 顶部导航
2. 首屏搜索与价值表达
3. 四个主入口：找工具、看教程、复制提示词、做对比
4. 按任务找工具
5. 免费专区入口
6. 热门工具推荐
7. 最新教程
8. 提示词精选
9. 热门对比
10. 投稿与合作

布局规则：

- 首屏不要堆资讯。
- 首页推荐工具不超过 8 个。
- 每个任务入口都要链接到工具、教程或提示词。
- 页面区块使用全宽背景区分，不要卡片套卡片。

## 14. 分类页布局规范

分类页目标：让用户知道这一类工具怎么选，并快速进入详情、教程和对比。

推荐结构：

1. 分类 H1 + 简短说明
2. 怎么选模块
3. 筛选器
4. 编辑推荐
5. 工具列表
6. 相关教程
7. 相关提示词
8. 相关对比
9. FAQ

布局规则：

- 桌面端可使用左侧筛选 + 右侧列表。
- 移动端筛选器折叠为抽屉或顶部横向 chips。
- 工具列表优先卡片网格，不做密集表格。

## 15. 详情页布局规范

详情页目标：回答“这个工具适不适合我，怎么开始用”。

推荐结构：

1. 工具头部：Logo、名称、定位、官网按钮、价格 Badge
2. 适合谁 / 不适合谁
3. 核心功能
4. 价格与免费额度
5. 优缺点
6. 上手教程
7. 可复制提示词
8. 替代工具
9. 相关对比
10. FAQ

布局规则：

- 桌面端可使用主内容 + 右侧信息栏。
- 右侧信息栏展示官网、价格、分类、更新时间。
- 移动端右侧信息栏下沉到正文前部。
- CTA 不要过多，主 CTA 为官网或教程。

## 16. 移动端适配规则

断点建议：

| 断点 | 宽度 | 规则 |
|---|---:|---|
| Mobile | `< 640px` | 单列布局 |
| Tablet | `640px - 1024px` | 双列或紧凑网格 |
| Desktop | `> 1024px` | 多列网格和侧栏 |

移动端规则：

- 页面左右 padding 16px。
- 首页搜索框按钮可换行或内联压缩，不能溢出。
- 工具卡片单列，卡片内按钮可横向排列或堆叠。
- 筛选器用折叠面板或横向滚动 chips。
- 对比表格允许横向滚动。
- 导航使用简洁菜单，保留搜索入口。
- 所有点击目标高度至少 40px。

## 17. 暗色模式规则

暗色模式是增强项，不应牺牲可读性。

### Dark Mode Token

| Token | 色值 | 用途 |
|---|---|---|
| `--color-bg` | `#0F172A` | 页面背景 |
| `--color-surface` | `#111827` | 卡片背景 |
| `--color-surface-muted` | `#1E293B` | 次级背景 |
| `--color-border` | `#334155` | 默认边框 |
| `--color-text` | `#F8FAFC` | 主文本 |
| `--color-text-muted` | `#CBD5E1` | 次级文本 |
| `--color-text-soft` | `#94A3B8` | 辅助文本 |
| `--color-primary` | `#60A5FA` | 主强调 |
| `--color-secondary` | `#A78BFA` | 辅助强调 |
| `--color-success` | `#34D399` | 免费/可用 |
| `--color-warning` | `#FBBF24` | 赞助/注意 |
| `--color-danger` | `#F87171` | 风险 |

规则：

- 暗色模式下不要使用纯黑背景。
- 卡片边框比阴影更重要。
- Badge 使用深色浅透明背景，保证文字对比。
- 表格斑马纹要非常轻，避免视觉噪音。

## 18. Tailwind class 使用建议

### 布局

| 场景 | 建议 |
|---|---|
| 页面容器 | 使用 `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8` |
| 文章正文 | 使用 `max-w-3xl` |
| 卡片网格 | 使用 `grid gap-4 sm:grid-cols-2 lg:grid-cols-3` |
| 首页大分区 | 使用 `py-10 sm:py-12 lg:py-16` |
| 卡片内间距 | 使用 `p-4` 或 `p-5` |

### 视觉

| 场景 | 建议 |
|---|---|
| 默认卡片 | `rounded-lg border bg-white` |
| 卡片 hover | `hover:border-blue-300 hover:shadow-sm` |
| 主按钮 | `bg-blue-600 text-white hover:bg-blue-700` |
| 次按钮 | `border bg-white hover:bg-slate-50` |
| Badge | `rounded px-2 py-0.5 text-xs font-medium` |
| Muted 文本 | `text-slate-600` |
| 主标题 | `text-3xl font-bold tracking-normal` |

### 规则

- 优先使用 Tailwind 语义组合，不在页面里随意写一次性颜色。
- 常用颜色、圆角、阴影应抽象为组件或 CSS token。
- 避免过长 class 重复出现在多个页面，工具卡片、教程卡片、Badge、按钮应组件化。
- 不使用负字距。
- 不使用单一蓝紫渐变铺满全站。
- 赞助、广告、合作标签必须有固定 class，不得随页面随意变化。
## 2026-05-10 首页 UI 丰富化重构记录

本次首页重构保持“中文 AI 工具选择 + 上手教程 + 场景方案 + 可复制提示词”的产品定位，不改变 Nuxt 4、Vue 3、TypeScript、Tailwind CSS 和 Nuxt Content 技术栈。

已落地规则：

- Header 使用 `bg-white/90`、`backdrop-blur`、`border-b`、`sticky top-0 z-50`，Logo 改为简单线性图标 + “AI工具箱”文字，右侧保留“提交工具”按钮。
- Hero 改为浅蓝紫渐变背景，包含柔和光斑、网格纹理、真实输入搜索框、热门搜索词 chips 和右侧 CSS 插画卡片。
- 首页主搜索框使用 `v-model` 绑定真实输入状态，支持中文输入法 composition、Enter 搜索、按钮搜索、热门词填入、清空按钮和空状态。
- 身份入口、免费专区、热门榜单、今日推荐、新手必看、工具对比、场景方案、提示词库、教程文章、用户投稿和工具网格均加入图标、渐变、封面或更明确的视觉层级。
- 商业推荐位必须显示“合作”或“广告/赞助”标记，且不使用弹窗和大面积横幅。
- 工具卡片统一展示图标、名称、分类、简介、免费状态、中文支持、平台、适合人群、最近更新、是否附教程和标签。
