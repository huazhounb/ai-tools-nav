# 中文 AI 工具导航内容产品 PRD

## 1. 项目定位

本项目是一个面向中文用户的 AI 工具选择与上手内容产品，不是“大而全工具黄页”。

核心定位：

> 帮中文用户最快找到、看懂并用上 AI 工具。

产品形态：

> AI 工具选择 + 上手教程 + 场景方案 + 可复制提示词 + 工具对比 + 榜单推荐。

MVP 的第一目标不是做账号体系、社区或厂商后台，而是先用 SEO 页面承接搜索流量，并通过结构化内容帮助用户完成决策。

## 2. 目标用户

| 用户类型 | 典型需求 | 优先承接页面 |
|---|---|---|
| AI 新手 | 不知道从哪个工具开始 | 首页、免费专区、新手教程 |
| 职场办公用户 | 写周报、做 PPT、总结文档、整理会议 | 办公分类页、教程页、提示词页 |
| 学生/论文用户 | 查资料、读论文、润色、引用整理 | 学术分类页、工具对比页、教程页 |
| 自媒体/内容创作者 | 标题、脚本、选题、配图 | 内容创作分类页、提示词库、场景教程 |
| 设计师/电商用户 | 生图、修图、商品图、海报 | 设计分类页、图像工具对比页 |
| 程序员 | AI 编程、代码解释、IDE 选择 | 编程分类页、Cursor/Trae 对比页 |
| AI 厂商 | 工具曝光、投稿、合作、广告 | 投稿页、合作页、后台审核 |

## 3. 核心价值

1. 帮用户选工具：用分类页、免费专区、对比页和榜单页解决“该选哪个”。
2. 帮用户用工具：用教程页和提示词库解决“怎么上手”。
3. 帮用户完成任务：用场景方案和页面内推荐链路解决“怎么从工具到结果”。
4. 帮搜索引擎理解内容：用稳定 URL、SEO meta、结构化数据和内链体系沉淀长期流量。
5. 帮厂商合规曝光：用投稿、赞助和合作页承接商业化，但必须透明标注。

## 4. 产品原则

| 原则 | 说明 | 落地方式 |
|---|---|---|
| 场景优先 | 用户按任务找工具，不按技术分类思考 | 首页和分类页优先展示任务入口 |
| SEO 优先 | 首页不是唯一入口 | 工具、分类、对比、教程、提示词都要可独立收录 |
| 教程优先 | 教程决定停留和复访 | 每个重点工具至少关联 1 篇教程 |
| 提示词优先 | 可复制内容提高即时价值 | 提示词页提供复制、变量说明、示例输出 |
| 对比优先 | 对比页承接高意图搜索 | 首批建设高搜索意图工具对比 |
| 免费优先 | “免费 AI 工具”是强流量入口 | MVP 必须包含免费专区 |
| 实测透明 | 不伪装深度评测 | 未实测内容标注“资料整理” |
| 广告透明 | 不混淆商业推荐和编辑推荐 | 赞助、合作、广告必须标注 |

复杂账号体系、评论系统、积分系统、收藏夹、厂商自助投放后台、大规模自动爬虫、多语言系统。

## 7. 首页模块

首页 SEO 价值：承接品牌词，向分类、工具、教程、提示词、对比页分发权重。

| 模块 | 内容 | 功能要求 |
|---|---|---|
| 首屏搜索 | 搜工具名、任务、场景 | 支持搜索建议，结果可跳转工具/教程/提示词 |
| 核心入口 | 找工具、看教程、复制提示词、做对比 | 四个入口必须在首屏可见 |
| 按任务找工具 | 写周报、做PPT、读论文、生成图片、写代码等 | 每个任务卡片关联工具、教程、提示词 |
| 热门工具推荐 | 6-8 个重点工具 | 必须显示推荐理由、免费/付费、适合人群 |
| 免费专区入口 | 免费 AI 工具合集 | 强导向 `/free-ai-tools` |
| 最新教程 | 近期教程卡片 | 显示场景、耗时、涉及工具 |
| 提示词精选 | 按办公、写作、学习、编程等场景展示 | 支持复制入口 |
| 热门对比 | Kimi vs 豆包、Cursor vs Trae 等 | 导向对比页 |
| 投稿与合作 | 提交工具、广告合作 | 明确投稿不等于推荐 |

## 8. 分类页模块

分类页 SEO 价值：承接“AI写作工具”“AI绘图工具”“AI编程工具”等分类词，并向工具详情、教程、提示词传递内链。

| 模块 | 内容 | 功能要求 |
|---|---|---|
| 分类标题与说明 | 分类定义、适合任务 | 不写空泛介绍，要说明用户能解决什么问题 |
| 怎么选 | 选择维度和推荐逻辑 | 例如免费额度、中文支持、上手难度、输出质量 |
| 工具列表 | 分类下工具卡片 | 支持免费、付费、国内可访问、适合人群标签 |
| 编辑推荐 | 3-5 个推荐工具 | 必须给推荐理由 |
| 免费工具筛选 | 免费/有免费额度 | 强化免费搜索需求 |
| 相关教程 | 分类下教程 | 帮用户上手 |
| 相关提示词 | 分类下提示词 | 提供可复制资产 |
| 相关对比 | 同类工具对比 | 承接决策需求 |
| FAQ | 常见问题 | 覆盖长尾搜索 |

## 9. 工具详情页模块

工具详情页 SEO 价值：承接工具品牌词、“工具名 怎么用”“工具名 免费吗”“工具名 替代品”等搜索。

| 模块 | 内容 | 功能要求 |
|---|---|---|
| 工具基本信息 | 名称、Logo、官网、分类、价格 | 官网外链需安全打开 |
| 一句话定位 | 工具解决什么问题 | 不复制官方空话 |
| 适合谁 | 目标用户和任务 | 给出具体场景 |
| 不适合谁 | 边界和限制 | 帮用户避坑 |
| 价格与免费额度 | 免费、试用、订阅 | 不确定时标注待确认 |
| 核心功能 | 3-6 个功能点 | 和用户任务绑定 |
| 优缺点 | 清晰列出 | 未实测不得夸大 |
| 上手步骤 | 简短步骤 | 链接到完整教程 |
| 可复制提示词 | 相关 prompt | 链接到提示词详情 |
| 替代工具 | 3-5 个 | 形成内链 |
| 相关对比 | 与竞品对比 | 导向对比页 |
| FAQ | 免费吗、国内能用吗、适合谁 | 覆盖长尾 SEO |

## 10. 对比页模块

对比页 SEO 价值：承接“X vs Y”“X 和 Y 哪个好”“X 替代品”等高意图搜索，优先级高。

| 模块 | 内容 | 功能要求 |
|---|---|---|
| 结论先行 | 直接给选择建议 | 第一屏必须出现 |
| 对比摘要表 | 价格、中文支持、适合场景、上手难度 | 用表格降低决策成本 |
| 分场景建议 | 办公、学习、编程、内容创作等 | 不只给单一胜负 |
| 关键差异 | 3-5 个核心差异 | 解释为什么 |
| 适合人群 | 谁选 A，谁选 B | 可执行 |
| 替代工具 | 其他选择 | 增加内链 |
| 相关教程 | 两个工具的上手教程 | 导向教程页 |
| FAQ | 哪个免费、哪个适合中文、哪个适合新手 | 覆盖长尾词 |

首批对比建议：

- Kimi vs 豆包
- DeepSeek vs 通义千问
- Cursor vs Trae
- Midjourney vs 即梦AI
- 秘塔AI搜索 vs Perplexity
- ChatGPT vs Claude

## 11. 教程页模块

教程页 SEO 价值：承接“怎么用 AI 做 PPT”“DeepSeek 写周报教程”“AI 论文润色教程”等操作型长尾词。

| 模块 | 内容 | 功能要求 |
|---|---|---|
| 教程目标 | 本教程完成什么任务 | 标题要包含任务和工具 |
| 适用人群 | 新手/职场/学生/运营等 | 帮用户判断是否继续读 |
| 准备材料 | 账号、素材、输入文件 | 降低失败率 |
| 操作步骤 | 分步骤说明 | 每步有明确动作 |
| 可复制提示词 | 直接可用 prompt | 必须可复制 |
| 示例输出 | 展示结果样例 | 帮用户判断质量 |
| 常见失败原因 | 账号、输入、提示词问题 | 提高完成率 |
| 替代工具 | 同任务其他工具 | 导向工具详情 |
| 相关对比 | 相关工具对比 | 导向对比页 |

教程不写泛泛 AI 评论，只解决具体工作流。

| 推荐工具 | 适合该 prompt 的工具 | 导向工具详情 |
| 相关教程 | 如何使用该 prompt | 导向教程页 |
| FAQ | 怎么改变量、适合哪个模型 | 覆盖长尾搜索 |

首批提示词方向：

- 周报总结
- PPT 大纲
- 小红书标题
- 公众号选题
- 短视频脚本

## 15. 简单后台模块

后台不承担 SEO，目标是支撑 MVP 内容生产和审核。

| 模块 | 功能 | MVP 要求 |
|---|---|---|
| 工具管理 | 新增、编辑、上下架工具 | 支持分类、标签、价格、推荐理由 |
| 投稿审核 | 查看投稿、通过、拒绝、补充信息 | 不做厂商自助账号 |
| 分类管理 | 分类名称、描述、SEO 标题 | 支持分类页 SEO |
| 教程管理 | 新增、编辑教程 | 支持关联工具、提示词、分类 |
| 提示词管理 | 新增、编辑 prompt | 支持变量说明和复制内容 |
| 对比页管理 | 管理对比对象和结论 | 支持对比表 |
| 榜单管理 | 榜单工具、排序规则 | 必须填写排名依据 |

MVP 后台可以是简单管理界面，不做复杂权限、多角色、支付和厂商登录。

## 16. 商业化模块

| 模块 | 页面/位置 | MVP 做法 | SEO/业务价值 |
|---|---|---|---|
| 投稿入口 | `/submit` | 免费投稿 + 人工审核 | 获取供给 |
| 赞助工具位 | 首页、分类页、详情页 | 显示“赞助”标签 | 初期广告收入 |
| 合作页 | `/cooperation` | 展示合作方式和联系表单 | 承接品牌合作搜索 |
| 内容合作 | 教程页、榜单页 | 标注“合作内容” | 厂商案例和教程变现 |
| 联盟链接 | 工具详情页 | 可选，必须不影响推荐结论 | SaaS 佣金 |

商业化底线：

- 赞助不等于编辑推荐。
- 商业内容必须标注。
- 排名依据必须透明。
- 不承诺自然排名。

## 17. 非 MVP 功能

| 功能 | 不做原因 | 后续触发条件 |
|---|---|---|
| 用户登录 | 对 SEO 冷启动帮助小 | 日活和收藏需求明确后 |
| 收藏夹 | 依赖账号体系 | 工具详情页访问稳定后 |
| 评论系统 | 审核成本高 | 有稳定社区运营能力后 |
| 积分系统 | 会偏离内容产品主线 | 暂不建议 |
| 厂商自助后台 | 涉及支付、审核、排名争议 | 商业收入稳定后 |
| 自动爬虫采集 | 容易低质和版权风险 | 有人工审核流程后 |
| 多语言 | 当前定位中文用户 | 中文 SEO 成熟后 |
| 复杂推荐算法 | 早期数据不足 | 有足够用户行为数据后 |

## 18. 验收标准

### 页面验收

| 页面 | 验收标准 |
|---|---|
| 首页 | 首屏出现搜索、四个主入口、任务入口；能进入分类、教程、提示词、对比 |
| 分类页 | 有分类说明、怎么选、工具列表、相关教程、相关提示词、FAQ |
| 工具详情页 | 有适合谁、不适合谁、价格/免费额度、优缺点、教程、提示词、替代品 |
| 免费专区 | 有免费工具列表、免费额度、限制说明、分类筛选 |
| 对比页 | 第一屏给结论，有对比表、分场景建议、FAQ |
| 教程页 | 有目标、步骤、可复制提示词、示例输出、相关工具 |
| 提示词页 | 有完整 prompt、变量说明、复制能力、示例输入输出 |
| 榜单页 | 有排名规则、工具列表、推荐理由、更新时间 |
| 投稿页 | 有表单、收录标准、审核说明、合作入口 |
| 后台 | 能管理工具、分类、教程、提示词、对比、榜单和投稿审核 |

### SEO 验收

每个公开页面必须具备：

- 唯一 `title`
- 唯一 `description`
- 规范化 URL
- H1 且每页仅一个核心 H1
- 面包屑或清晰内链
- Open Graph 基础信息
- JSON-LD：工具详情、FAQ、文章、面包屑按页面类型配置
- sitemap 收录公开页面
- robots 不屏蔽核心页面

### 内容验收

- 首批工具：100-200 个高质量工具，不追求数量堆叠。
- 首批分类：写作、办公、学习、设计、视频、编程、搜索、效率。
- 首批教程：至少 20 篇，必须包含可复制提示词。
- 首批提示词：至少 50 条，按场景组织。
- 首批对比：至少 6 篇，必须给结论和对比表。
- 首批榜单：至少 4 个，必须说明排名依据。

### 产品边界验收

- 没有复杂账号体系作为 MVP 主线。
- 没有评论、积分、收藏夹作为 MVP 依赖。
- 没有把首页做成资讯流。
- 没有把广告伪装成自然推荐。
- 每个页面都能说明 SEO 价值和用户决策价值。
