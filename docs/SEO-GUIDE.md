# SEO 指南

## 通用规则

- 每个可索引页面必须有唯一 H1。
- 每类页面必须使用 `useSeoMeta`。
- 动态详情页必须设置 canonical。
- 核心正文必须服务端可渲染，不要只放在客户端交互后。
- 页面应包含 FAQ、相关推荐和内部链接。
- JSON-LD 统一通过 `app/utils/schema.ts` 或 `JsonLd` 组件输出。

## H1 规则

- 首页 H1 应表达产品核心价值。
- 分类页 H1 使用 `{分类名}工具推荐`。
- 工具页 H1 使用工具名称。
- 教程、提示词、对比、榜单详情页 H1 使用内容标题。

## canonical 规则

- canonical 基于 `NUXT_PUBLIC_SITE_URL` 和当前 path。
- 动态页应避免 query 参数产生重复 canonical。
- `/tools/free` 与 `/free-ai-tools` 的 canonical 归属待确认。

## FAQ 规则

- 分类页至少 4 至 5 个 FAQ。
- 工具详情页至少 5 个 FAQ。
- 教程、提示词、对比、榜单详情页应提供与当前任务相关的 FAQ。
- FAQ 文案必须回答真实选择和使用问题，不写空泛套话。

## sitemap 规则

- `server/routes/sitemap.xml.get.ts` 负责输出 sitemap。
- 应包含首页、静态列表页、分类页、工具页、教程页、提示词页、对比页、榜单页和场景页。
- 新增 slug 后要确认 sitemap 是否自动覆盖。

## robots 规则

- `server/routes/robots.txt.get.ts` 负责输出 robots。
- 默认允许搜索引擎抓取公开内容页。
- 后台路径应禁止索引，规则是否已包含 `/admin` 待确认。

## 内链规则

- 首页链接到分类、工具、教程、提示词、对比和榜单。
- 分类页链接到工具详情、相关教程、相关提示词、相关对比和相邻分类。
- 工具详情页链接到替代工具、相关教程、相关提示词和相关对比。
- 教程详情页链接到使用工具、相关提示词和相关教程。
- 提示词详情页链接到相关工具、相关教程和相关提示词。
- 对比页链接到参与对比工具和相关教程。
- 榜单页链接到工具详情和相关对比。
