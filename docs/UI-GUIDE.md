# UI 指南

## 视觉风格

- 内容产品 + 效率工具。
- 浅色主题，蓝紫轻科技风格。
- 中等信息密度，优先清晰阅读和快速扫描。
- 使用卡片、徽标、图标和轻量渐变增强层次。
- 避免黑客风、赛博朋克、老式网址导航和纯白卡片堆叠。

## 色彩 token

建议沿用现有设计文档中的色彩：

```css
--background: #F8FAFC;
--card: #FFFFFF;
--primary: #2563EB;
--secondary: #7C3AED;
--success: #10B981;
--warning: #F59E0B;
--text-main: #0F172A;
--text-muted: #475569;
--border: #E2E8F0;
```

## 卡片规范

- 工具卡片可使用 16px 至 18px 圆角。
- 内容卡片白底、细边框、轻阴影。
- hover 可轻微上浮，边框变蓝。
- 不要把页面大区块全部做成嵌套卡片。

## 按钮规范

- 主按钮：蓝色背景，白色文字，用于搜索、提交、查看详情等主要动作。
- 次按钮：白底或浅蓝底，用于筛选、查看更多。
- 图标按钮：用于复制、清空、外链等明确小动作。
- 移动端按钮高度不低于 40px。

## Badge 规范

- 免费：绿色或浅绿。
- 有免费额度：蓝色。
- 付费：灰色或中性。
- 合作/赞助/广告：黄色或琥珀色，必须明确标注。
- 教程、评测、技巧、对比：使用低饱和标签色。

## 工具卡片规范

- 顶部展示 `BrandIcon`、工具名称、分类。
- 右上角展示免费状态和是否附教程。
- 中间展示一句话简介、适合人群、平台、中文支持。
- 底部展示标签、更新时间、查看详情。
- 图标优先使用 `public/brand-icons/` 本地图标。

## 教程卡片规范

- 封面应有渐变背景、关键词、类型标签和工具图标。
- 内容区域展示标题、摘要、适合人群、预计耗时、更新时间和阅读量。
- 不应只显示纯色块或纯文本列表。

## 提示词卡片规范

- 顶部展示用途或场景标签。
- 中间展示 Prompt 摘要。
- 底部提供复制按钮和查看详情按钮。
- 复制成功需要有“已复制”反馈。

## 榜单卡片规范

- 展示榜单名称、更新时间、Top 3 工具和适合人群。
- 详情页工具列表应展示排名、Logo、推荐理由和查看详情。
- 排名规则必须在正文中解释，避免只给名单。

## 移动端规则

- 工具卡片单列显示。
- 筛选项横向滚动或折叠。
- 对比表格允许横向滚动。
- Prompt 正文、代码、长链接不得溢出。
- 顶部导航移动端不能撑爆，必要时收起为菜单。
