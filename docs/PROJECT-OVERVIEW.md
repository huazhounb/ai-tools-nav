# 项目总览

## 项目背景

中文用户对 AI 工具有明确需求，但常见导航站容易停留在“工具黄页”层面：只列工具名称、官网和一句简介，缺少真实任务场景、上手教程、提示词模板和工具对比。本项目希望把 AI 工具导航做成内容产品，帮助用户从“知道工具”走到“完成任务”。

## 目标用户

- AI 新手：需要低门槛入口、免费工具和基础教程。
- 学生与论文用户：需要论文大纲、文献总结、长文档阅读和写作规范。
- 职场办公用户：需要周报、会议纪要、PPT、文档处理和数据分析。
- 自媒体与内容创作者：需要选题、脚本、标题、文案和图片生成。
- 设计师与运营：需要海报、视觉灵感、品牌物料和电商图。
- 程序员：需要代码补全、解释、重构、测试和项目理解。
- AI 工具厂商：需要投稿和后续商业合作入口。

## 核心价值

- 按任务而不是按厂商名称组织工具。
- 每个 SEO 页面都提供可索引正文、FAQ、相关推荐和内链。
- 把工具、教程、提示词、对比、榜单互相连接。
- 明确免费情况、中文支持、平台形态、适合人群和使用边界。
- 广告和合作位明确标注，不干扰阅读。

## MVP 范围

- 首页
- 免费工具页
- 分类总页与分类详情页
- 工具详情页
- 教程列表页与教程详情页
- 提示词列表页与提示词详情页
- 工具对比列表页与详情页
- 榜单列表页与详情页
- 场景页
- 投稿页
- 简单后台审核页
- sitemap、robots、canonical、JSON-LD
- 本地品牌图标管理

## 非 MVP 功能

- 完整账号体系
- 评论系统
- 收藏夹
- 积分系统
- 厂商自助投放后台
- 大规模自动爬虫
- 多语言系统
- 复杂搜索索引服务

## 当前完成情况

- Nuxt 4 工程骨架已建立。
- 主要页面路由已存在，源码在 `app/pages/`。
- `data/comprehensive.ts` 聚合了工具、分类、教程、提示词、对比和榜单 mock 数据。
- `content/` 已有教程、提示词、榜单、场景和对比 Markdown 示例。
- `server/` 已有投稿 API、简单审核接口、sitemap 和 robots 路由。
- `public/brand-icons/` 已有一批本地品牌图标。
- `.codex/skills/` 已有产品、UI、SEO、内容和工程 skills。

## 后续规划

1. 先修复中文乱码和搜索交互问题。
2. 扩充每个分类的工具、提示词、教程和对比关联。
3. 把 mock data 逐步迁移到关系型数据库。
4. 增加工具点赞、榜单权重、失效检测和人工审核流程。
5. 增强 SEO 内容质量，避免空壳页和批量灌水。
