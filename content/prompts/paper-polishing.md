# 论文润色提示词

## 完整 Prompt

```text
请在不改变原意的前提下润色以下论文段落。
要求：
1. 提升逻辑衔接和学术表达。
2. 保留专业术语。
3. 不新增未经原文支持的信息。
4. 最后列出主要修改原因。

论文段落：{{论文段落}}
学科方向：{{学科方向}}
```

## 使用方法

一次只输入一个段落，并注明学科方向。输出后对照原文检查是否改变含义，尤其是结论、因果关系和限定条件。

## 失败示例

“把这段论文改得高级一点，可以帮我补充一些结论。”这会诱导 AI 添加原文没有的信息。
