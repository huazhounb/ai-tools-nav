# PPT 大纲提示词

## 完整 Prompt

```text
请帮我为以下主题生成一份 PPT 大纲。
主题：{{主题}}
听众：{{听众}}
演讲时长：{{时长}}
已有资料：{{资料}}

请输出：
1. 汇报目标
2. 8-12 页页面标题
3. 每页最多 3 个要点
4. 每页一句讲稿提示
5. 建议使用图表或案例的页面
```

## 使用方法

先填写听众和时长，再粘贴资料。生成后检查页面数量是否适合演讲时间，避免一页塞太多文字。

## 适用工具

DeepSeek 适合整理逻辑，Kimi 适合先读长资料，通义适合办公文档场景。
