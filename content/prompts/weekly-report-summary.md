# 周报总结提示词

## 使用场景

适合把一周的任务、进展、问题和计划整理成周报初稿。适用工具包括 DeepSeek、豆包、通义等中文对话工具。

## 完整 Prompt

```text
请根据以下工作记录，按“本周完成、关键进展、遇到问题、下周计划”整理一份简洁周报。
要求：
1. 语气专业克制，不夸大成果。
2. 保留可量化结果。
3. 不确定的信息标注“待确认”。
4. 输出适合发给直属领导的版本。

工作记录：{{工作记录}}
岗位/团队：{{岗位或团队}}
汇报对象：{{汇报对象}}
```

## 变量说明

- `工作记录`：本周完成的任务、会议、交付物和问题。
- `岗位或团队`：帮助 AI 调整表达重点。
- `汇报对象`：例如直属领导、项目组或客户。

## 失败示例

“帮我写一份很厉害的周报”会导致内容夸张、事实不清。更好的做法是提供真实记录和输出结构。
