# 用 Kimi 总结论文和长 PDF

Kimi 适合处理长文本和资料整理，但不能替代正式文献阅读。本教程的目标是帮你完成第一轮论文理解：看清研究问题、研究方法、核心结论和需要回到原文核对的位置。

## 适合人群

- 需要快速了解论文内容的学生
- 做选题调研的论文写作者
- 需要阅读研报、访谈和长文档的职场用户

## 操作步骤

1. 上传论文 PDF 或粘贴正文，尽量保留摘要、方法、实验和结论。
2. 先让 Kimi 输出论文框架，不要直接要求“写读后感”。
3. 对方法、数据来源、实验结果逐项追问。
4. 把 AI 给出的引用句子回到原文核对页码和上下文。

## 可复制提示词

```text
请阅读这篇论文，按以下结构整理：
1. 研究问题
2. 研究方法
3. 数据来源
4. 核心结论
5. 局限性
6. 可以引用但需要回原文核对的句子

要求：不要编造引用，不确定的信息标注“需核对”。
```

## 常见错误

- 只总结摘要：容易忽略方法和局限。
- 直接复制 AI 输出做引用：引用必须回到原文确认。
- 一次问太大：复杂论文建议分章节追问。
