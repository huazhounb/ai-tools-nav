# 用 DeepSeek 写一份可直接修改的周报

这篇教程适合职场新人、项目成员和需要定期汇报的办公用户。目标不是让 AI 直接替你编成果，而是把零散工作记录整理成一份可修改、可核对、语气克制的周报初稿。

## 准备材料

- 本周完成的任务列表
- 关键数据或交付物
- 遇到的问题和阻塞
- 下周计划

## 操作步骤

1. 先把工作记录按项目列出来，不需要一开始就写得很完整。
2. 让 DeepSeek 按“本周完成、关键进展、问题风险、下周计划”输出。
3. 要求语气专业克制，不要夸大成果。
4. 人工核对项目名、日期、数字和负责人。

## 可复制提示词

```text
请根据以下工作记录，按“本周完成、关键进展、遇到问题、下周计划”整理一份简洁周报。
要求：
1. 语气专业克制，不夸大成果。
2. 保留可量化结果。
3. 不确定的信息标注“待确认”。
4. 输出适合发给直属领导的版本。

工作记录：
{{粘贴本周工作记录}}
```

## 常见错误

- 输入太少：只写“做了项目”，AI 会输出空泛内容。
- 不限制语气：容易生成像宣传稿的表达。
- 不核对数字：周报里的完成率、日期和人数必须人工确认。
