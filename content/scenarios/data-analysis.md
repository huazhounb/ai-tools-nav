# AI 数据分析场景方案

## 场景目标

用 AI 辅助理解表格数据、解释指标变化、生成图表建议和整理分析结论。它适合做分析助手，不适合替代数据口径确认。

## 推荐流程

1. 先说明数据字段和业务背景。
2. 让 AI 检查缺失值、异常值和口径问题。
3. 要求 AI 给出可视化建议，而不是直接下结论。
4. 最后人工确认数据来源和业务解释。

## 可复制提示词

```text
请分析以下表格数据，先解释字段含义，再检查异常值和缺失值，最后给出 3 个可能的业务结论和对应图表建议。
业务背景：{{业务背景}}
数据：{{表格数据}}
```

## 注意事项

不要把敏感用户数据直接输入公共 AI 工具。涉及业务决策时，必须回到原始数据源核对。
